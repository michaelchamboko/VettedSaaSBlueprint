## Permanent instruction

Missing editorial evidence is unfinished work, not by itself a blocker. When an import requires EditorialEvidenceV2, complete `.agents/skills/eleanor-editorial/SKILL.md` before submitting another validation result. That skill remains authoritative for the full rewrite, different-model-family cleanse, fidelity checks, and receipt generation.

Never substitute LandingEditorialReviewV1, another article's receipt, or fabricated attestations. Submit the current artifact, genuine matching editorial receipt, required quality evidence, and correctly bound work packet.

Do not retry unchanged failing input. Diagnose the failure and complete the relevant repair first. After three unsuccessful repairs, stop speculative retries and investigate the underlying assumption; continue when a verified remedy is available. Preserve existing retry counters.

Record a durable blocker only when a specific, demonstrated obstacle prevents completing the work. Include the cause, attempted recovery, and exact requirement for resumption. Genuine article-specific blockers follow the existing continuation policy; shared capability, model-access, integrity, or release failures stop the run.

Preserve the immutable snapshot, entry order, editorial standards, and every publication gate. Missing work does not justify skipping an article. Completed processing does not establish publication.
