# Synthetic Landing Workflow Examples

These examples use synthetic products, synthetic domains, and synthetic UUIDs only. They are reference shapes for execution agents, never a real page, evidence ledger, or owner approval.

Validated against the existing repository schemas by `tests/landing-workflow-examples.test.ts`.

| File | Purpose |
| --- | --- |
| `workflow-task-packet.md` | Owner handoff produced by `npm run landing:workflow:inspect -- --format task`. |
| `product-evidence-pack.json` | Synthetic product evidence ledger input. |
| `design-direction.json` | Synthetic Stage 0 design direction. |
| `presentation-recipe.json` | Synthetic presentation recipe. |
| `page-blueprint.json` | Synthetic PageBlueprint draft. |
| `validation-failure.json` | Synthetic structured validation-failure result. |
| `agent-handoff.md` | Completed quality handoff that continues to automatic release. |
