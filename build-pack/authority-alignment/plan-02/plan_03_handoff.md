# Plan 3 handoff — agent-boundary evaluation

Plan 3 remains unstarted.

## Evidence carried forward

- One main loop can own authority, implementation, verification, release, and durable evidence.
- Independent current-head review is a valid separate boundary because it benefits from context isolation.
- The article-import heartbeat wording created authority drift and should not be used as evidence that a permanent supervising agent is necessary.
- Neon supplies retrieval and impact context; it does not justify a separate repository-intelligence agent.
- BuildRunner is durable lifecycle state, not an agent.

## Questions Plan 3 must measure

1. Which current agent or reviewer boundaries have distinct permissions or independent-verification value?
2. Which boundaries merely compensate for context size or duplicate main-loop work?
3. For each retained boundary, what measurable reduction in errors, elapsed time, or context pressure justifies it?
4. Which skills can provide progressive disclosure without another agent?
5. Which handoffs lose evidence or create conflicting authority?

## Required raw evidence

- Actual task transcripts and tool-call timelines.
- Context and retry data where available.
- Review findings by source and severity.
- Duplicate work and handoff failures.
- Permission boundaries and release receipts.

Do not infer consolidation from role names. Do not create agent changes until the measurements support them.
