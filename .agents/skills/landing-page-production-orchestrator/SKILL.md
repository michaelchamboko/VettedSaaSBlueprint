# Supervised content production

Use four stages: decide the buyer question and exact approved URL; gather bounded source-linked evidence; run one quality result; validate, merge, and verify the Vercel deployment. Preserve disclosures, limitations, direct destinations, metadata, accessibility, and internal links. Specialist reviews are repair inputs, not release authorities.

For a new or materially changed public page, read and apply `design-taste-frontend` and the project-local Impeccable skill before qualifying UI implementation. Impeccable is the design authority. Run its `context` and `shape` checks before implementation; inspect desktop and mobile; then run `critique`, `audit`, `detect`, one bounded correction pass, and `polish`. The first qualifying page also runs `init`, `document`, and `extract`; later pages reuse its recorded identity. Use Emil design-engineering guidance only for changed interaction or motion, and route the other specialist skills only when their feature trigger is present.

Within authoring, complete the mandatory full-article workflow in `../eleanor-editorial/SKILL.md` after the evidence-backed draft and before candidate validation. Rewrite every editable prose field, complete the different-model-family cleanse and final fidelity review, and require 5/5 CLEAN. Save `EditorialEvidenceV2` in `build-pack/editorial` and reuse it only for an unchanged artifact fingerprint at the same revision. This adds no schedule, service or deployment authority.
